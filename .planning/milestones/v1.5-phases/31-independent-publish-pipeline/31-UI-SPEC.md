## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, tight inline spacing |
| sm | 8px | Compact gaps between badges/meta rows |
| md | 16px | Default padding/gaps inside cards, sections |
| lg | 24px | Section separation inside dialog/page blocks |
| xl | 32px | Major block separation |
| 2xl | 48px | Page-level vertical rhythm (rare in admin dialog) |
| 3xl | 64px | Reserved, avoid in dense admin surfaces |

Exceptions: `min-h-11` (44px) touch targets for buttons/links/inputs; 12px/16px radius already tokenized as `--radius-card`/`--radius-dialog`; spinner `h-4 w-4` (16px) aligned to scale.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0f0a1a` (`--color-canvas`) | Page/dialog background canvas |
| Secondary (30%) | `#1a1025` (`--color-surface`) | Cards, dialogs, elevated admin surfaces |
| Accent (10%) | `#8b5cf6` (`--color-accent`) / `#7c3aed` strong / `#a78bfa` soft | Accent reserved for: primary action buttons (`bg-accent-strong`), focus ring (`accent-soft`), active/interactive border hover, published/scheduled/publishing status badges, links/CTAs, selected chips/toggles |
| Destructive | `#f87171` (`--color-danger`) / `#fecaca` (`danger-soft`) | Destructive/error states only: failed status badge/text, validation/error alerts, destructive confirm actions |

Accent reserved for: primary CTA fill, accent borders/hover on interactive controls, status emphasis for published/scheduled/publishing, links to Facebook/Instagram/Integrações, focus-visible ring. **Never** use accent as generic body text or non-interactive decoration.

Semantic mapping (existing, preserve):
- `failed`: `border-danger bg-[rgba(248,113,113,0.12)] text-danger-soft`
- `published`: `border-accent bg-[rgba(139,92,246,0.12)] text-fg`
- `publishing/scheduled`: `border-accent/40 bg-[rgba(139,92,246,0.08)] text-fg` (+ spinner for publishing)
- `draft/none/unknown`: `border-line bg-canvas text-fg-muted`

### Phase 31 Required Copy (pt-BR, safe, actionable)

| Context | Copy Contract |
|---------|---------------|
| Provider label | `Facebook` or `Instagram` visible on every status/audit item. |
| IG published | `Publicado no Instagram.`; link label `Ver post no Instagram`; missing link fallback `Publicado no Instagram. Link indisponível.` |
| FB published | Keep existing `Publicado no Facebook.` / `Ver post no Facebook` / `Link indisponível.` |
| Ambiguous/reconciliation required | `Publicação precisa de verificação antes de nova tentativa. Vamos conferir o status no Instagram antes de publicar novamente.` (or backend-provided `retry_block_reason`; UI must render it as text). |
| Rate limit / daily limit blocked (PUBL-05) | Backend-provided safe pt-BR `last_error`/`retry_block_reason` must be displayed; pattern: `Publicação bloqueada temporariamente pelo limite do Instagram. Tente novamente mais tarde.` Do not encourage rapid retries. |
| IG not ready / needs reconnect (PUBL-01/D-07) | Reuse existing readiness/reconnect messaging: actionable reason + link `Abrir Integrações` to `/admin/integracoes`. |
| Audit history heading | `Histórico de tentativas` |
| Audit empty | `Nenhuma tentativa registrada.` |
| Audit load error | `Não foi possível carregar o histórico de tentativas. Tente novamente em alguns instantes.` |
| Unknown/unavailable field | `Indisponível` (never expose raw internal error/token). |

All user-facing strings must be pt-BR. No tokens, secrets, raw Graph payloads, stack traces, or internal IDs beyond safe operational IDs explicitly allowed by PUBL-03 (external post ID, container/media IDs, permalink).

|--------------|--------|----------|------|
| Loading | Existing card with `Carregando...` | Fetch provider-aware social posts on mount/token change. | Text visible; no spinner required beyond existing patterns. |
| Load error | Danger card + retry button | `Tentar novamente` reloads list. | `role` not needed; button reachable, min-h-11. |
| Empty | Existing empty card | Keep current copy + CTA to `/admin/review`. | Heading/body/link semantic. |
| List item | Card per social post item, keyed by provider+job/post id | Show provider label, job title, job ID, status badge, status detail, attempts/timestamps, IDs/permalink when available, safe error/reason, audit history, retry action. | `article`/`li` structure preserved; links/buttons labeled. |
| Provider identity | Visible label/chip or text row | Display `Plataforma: Facebook` / `Plataforma: Instagram` (or badge). Same job may appear twice (one per provider) without collision. | Text content, not color-only. |
| Status detail | Existing detail block patterns | Render backend-provided `status_label`, `last_error`, `retry_block_reason`, `scheduled_at`, `published_at`, `attempts`, `next_retry_at` when present. Timestamps formatted with `America/Sao_Paulo`, `pt-BR`, 24h. | Dates as text; include timezone in visible copy where already used. |
| IDs/permalink | Metadata rows | Show `ID externo`/`ID do post` and `Permalink` when available. Prefer `published_permalink`; fallback `published_url`. Container/media IDs may be shown in compact audit/details only when useful and safe. | External links `target="_blank" rel="noopener noreferrer"`. |
| Audit history | Compact expandable section per item (`Detalhes da tentativa` / `Histórico de tentativas`) | Lazy-fetch logs on expand/open; cache per item; show attempt number, result, safe summary/message, timestamp. | Rate-limit blocked (PUBL-05) | Failed/blocked actionable state | Show backend safe limit message; `can_retry` expected false/no storm. No countdown spam. | Informative text; no disabled-button-only explanation. |

## Data Contract (UI-facing, safe fields only)

UI may render only safe fields from admin APIs:

| Field | Use | Notes |
|-------|-----|-------|
| `provider` | `facebook`/`instagram` label | Required for per-platform independence. |
| `status`, `status_label` | Badge + text | Backend-provided pt-BR label preferred. |
| `last_error`, `retry_block_reason` | Actionable safe message | Render as text; no HTML. |
| `published_at`, `scheduled_at`, `next_retry_at`, `ig_last_reconciled_at` | Timestamps | Format pt-BR America/Sao_Paulo. |
| `attempts` | Audit/status detail | Integer. |
| `external_post_id`, `ig_container_id`, `ig_media_id` | Safe operational IDs | Show compactly; copyable optional, not required. |
| `published_permalink`, `published_url` | Public post link | Prefer permalink; fallback URL; open new tab. |
| `reconciliation_required`, `reconciliation_state` | Blocked reconciliation UX | Drive clear messaging; never auto-retry. |
| `can_retry` | Retry CTA enablement | Backend is source of truth. |
| Social logs: `created_at`, `attempt`, `result`, `error_code`, `message`, `response_summary` | Audit history | Safe/sanitized only; no tokens/secrets/raw payloads. |

**Never render:** access tokens, encrypted tokens, raw Graph responses, secrets, Authorization headers, internal stack traces.

## Responsive / Layout

- Mobile-first; admin surfaces already operate in narrow widths. Cards stack in one column (`grid-cols-1`).
- Touch targets >= 44px (`min-h-11`) for all buttons/links/inputs.
- Long IDs/URLs/errors use `[overflow-wrap:anywhere]`.
- Audit history details should not push primary retry/status below excessive scroll; keep compact (max visible rows or scroll container with modest max height).
- Dialog remains existing responsive dialog pattern; no new full-screen takeover.

---

## Accessibility

- Status must not be color-only: always pair badge color with `status_label` text.
- Retry/loading state announced by visible text change (`Tentando novamente...`); optional `aria-busy` on button.
- External links include visible label and `rel="noopener noreferrer"`.
- Expandable audit history uses semantic `<details>/<summary>` or button with `aria-expanded`/`aria-controls`.
- Error messages use `role="alert"` only for immediate form/action errors; persistent status warnings use normal text.
- Preserve existing focus-visible ring (`outline-accent-soft`).
