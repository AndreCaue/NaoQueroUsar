<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin/API → publish pipeline | Internal trusted control invokes publish/retry; must enforce authz and idempotent state transitions. |
| Backend → Meta Graph API | External boundary; responses/timeouts/errors are untrusted and may be ambiguous. |
| Backend → public IG media URL | External fetch by Meta; URL must be validated/public HTTPS and exact intended media. |
| Pipeline → DB/logs/admin responses | Persistence and observability boundary; secrets/tokens must never cross. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
