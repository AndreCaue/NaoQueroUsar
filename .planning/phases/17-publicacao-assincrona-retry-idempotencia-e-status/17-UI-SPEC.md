# Phase 17 — UI Design Contract

> Visual and interaction contract for social publishing status visibility and manual retry in the admin. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope (UI-01, UI-02, D-13..D-15):** Admin UI only — (1) status social por vaga no fluxo de revisão/edição (`ReviewQueue`/`ReviewRow`/`EditJobDialog`) e (2) nova visão/lista simples no admin de posts/vagas sociais para acompanhamento pós-aprovação, com badge/status, erro resumido, link do post publicado e ação "Tentar novamente" para casos elegíveis. **Fora de escopo:** board público, geração/edição de draft (Phase 16, exceto integração estrita de status/retry), sincronização/remoção de post no Facebook, analytics/métricas, Integrações Meta além de consistência de orientação de reconexão.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0f0a1a` (`canvas` token) | App/page backgrounds, input/read-only surfaces, table/list canvas |
| Secondary (30%) | `#1a1025` (`surface` token) + line/border tokens (`line`, `line-strong`) | Cards, dialog/list panels, rows, dividers, neutral containers |
| Accent (10%) | `#8b5cf6` / `#a78bfa` / `#7c3aed` (accent tokens: `accent`, `accent-soft`, `accent-strong`) | Primary CTA buttons, focus-visible outlines, active/selected controls, links to published post |
| Destructive | `#f87171` (danger tokens: `danger`, `danger-soft`) | Destructive/failed error emphasis, permanent-failure messaging, danger-styled actions only when applicable |

Supporting neutrals (existing): foreground `#e2e8f0` (`fg`), muted `#b8a9cc`/equivalent (`fg-muted`). Subtle tinted surfaces follow existing patterns (e.g. `bg-[rgba(139,92,246,0.12)]`, `bg-[rgba(248,113,113,0.12)]`).

**Accent reserved for:** primary action buttons (e.g. "Tentar novamente" when eligible and presented as primary action), focus-visible outlines, selected/active navigation or filter state (if used), and the **link "Ver post no Facebook"**. Accent must **not** be applied to all badges, all borders, or all interactive-looking text.

**Status badge color mapping (D-14, restrained — not accent-colored by default):**

| Estado (badge pt-BR) | Visual treatment | Text/icon |
|----------------------|------------------|-----------|
| `Sem rascunho` | Neutral: `border-line`, `bg-canvas`, `text-fg-muted` | 14px/400 |
| `Rascunho` | Neutral: `border-line`, `bg-canvas`, `text-fg-muted` | 14px/400 |
| `Agendado` | Subtle info: `border-line` or `border-accent`-subtle, `bg-[rgba(139,92,246,0.08)]`, `text-fg` | 14px/400; show scheduled context separately |
| `Publicando` | Subtle info/progress: `bg-[rgba(139,92,246,0.08)]`, `text-fg` + `Spinner` (14–16px) allowed | 14px/400; indicates in-flight |
| `Publicado` | Success (restrained, non-accent fill): `border-accent`, `bg-[rgba(139,92,246,0.12)]`, `text-fg` or `text-accent-soft` for label only if contrast-safe; prefer readable `text-fg` | 14px/400 + link affordance separate |
| `Falhou` | Danger emphasis (restrained): `border-danger`, `bg-[rgba(248,113,113,0.12)]`, `text-danger-soft` | 14px/400/600 label allowed for salience |
| `Cancelado` | Neutral muted: `border-line`, `bg-canvas`, `text-fg-muted` | 14px/400 |

All badges use rounded pill/chip shape consistent with admin (`rounded-full`/equivalent) with sufficient padding to meet 44px row tap clarity (badge itself need not be 44px tall, but adjacent actions must be).

## Component & Interaction Contracts

### Surfaces (D-13)

1. **Revisão/Edição por vaga (`EditJobDialog` and/or review row context):**
   - Render a `Status da publicação no Facebook` block for the job's social post when status data exists (or a `Sem rascunho` state when absent but contextually relevant).
   - Show: badge (D-14), helper/erro resumido, `last_error` area when failed/blocked, scheduled/published timestamps as available (pt-BR), `Ver post no Facebook` link when published URL/id-link available, and `Tentar novamente` when eligible (D-15).
   - Placement: near existing "Post para Facebook" draft section (below draft controls/preview or as a sibling status panel) with clear separation (`border-t border-line` or bordered panel `bg-canvas`/`bg-surface`).

2. **Nova visão/lista simples de posts/vagas sociais (admin):**
   - Route/page in admin area (exact path discretionary, e.g. `frontend/app/admin/social-posts/page.tsx` + client component) linked from admin navigation consistent with existing admin IA.
   - List items/cards/rows show at minimum: identificação da vaga (título + id/contexto curto), badge de status, erro resumido (quando houver), link do post publicado (quando disponível), horário agendado/publicado quando aplicável, e `Tentar novamente` quando elegível.
   - Keep operational and simple (no charts, no metrics, no complex filters beyond optional basic status filter if trivial; pagination/limit acceptable if provided by API).

3. **Fila de revisão (`ReviewRow` / `ReviewQueue`):**
   - Add compact social status indicator per row (badge + optional minimal hint iconography not required) so admin can scan agendado/publicando/publicado/falhou without opening dialog.
   - Row-level retry may be included **only** if it can reuse same idempotent flow and clear in-flight state; otherwise row shows status and directs to dialog/list for action. Eligibility rules identical (D-15).

### States & eligibility (D-14, D-15)

| State | Badge | Error area | Published link | Retry action |
|-------|-------|------------|----------------|--------------|
| Sem rascunho | `Sem rascunho` | none | none | hidden |
| Rascunho | `Rascunho` | none | none | hidden |
| Agendado (futuro/normal) | `Agendado` | none (unless backend provides safe note) | none | hidden/disabled with "Aguardando horário agendado" |
| Publicando | `Publicando` + spinner | none (or neutral "em andamento") | none | hidden/disabled (no duplicate click/send) |
| Publicado | `Publicado` | none | `Ver post no Facebook` when available | hidden |
| Falhou (elegível, conectado, não publicado) | `Falhou` | safe pt-BR summary shown | none | `Tentar novamente` enabled (44px) |
| Falhou (reconexão necessária / não elegível) | `Falhou` | reconnection/blocked guidance + `Abrir Integrações` | none | hidden or disabled with explicit guidance |
| Cancelado (se aplicável) | `Cancelado` | none/neutral | none | hidden |

**Retry interaction contract (D-12):** single-flight per post in UI (disable button + loading label while request pending); ignore/dedupe rapid repeat clicks client-side; always refresh status from server response/refetch; handle idempotent no-op as neutral success feedback, not as error.

**Loading states:** use existing spinner/skeleton/text patterns (`Carregando...` / inline `Spinner`) consistent with `IntegrationsClient` and `ReviewQueue`; do not block unrelated page actions.

**Read-only/immutability cues:** published/frozen/processing states must not imply the Facebook post can be edited or removed (fire-and-forget, PUB-08).

### Links & navigation
- `Ver post no Facebook`: external `<a>` with `target="_blank"` and `rel="noopener noreferrer"`, accent/underline affordance consistent with admin links, visible label text (not icon-only).
- `Abrir Integrações`: navigates to `/admin/integracoes` (existing screen) for reconnect flow.
- `Ir para a fila de revisão`: navigates to existing review queue route.

## Accessibility & Motion

- All interactive elements ≥ 44px touch target (`min-h-11`) with clear visible focus using existing accent focus-visible outline treatment.
- Status must not rely on color alone: always pair badge color with **pt-BR text label** (D-14); errors include text.
- `Publicando` spinner accompanied by visible text (`Publicando` / helper).
- External links announce purpose via text ("Ver post no Facebook"); avoid ambiguous "clique aqui".
- Async updates/retry feedback exposed via existing toast/live feedback patterns (`ToastProvider`) and/or inline status region updates; avoid focus loss on background refresh.
- Honor reduced motion preferences already present in admin base; no decorative animation required (spinner acceptable if system allows).
