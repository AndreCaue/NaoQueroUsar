<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Backend worker/pipeline -> Postgres | Claim/estado de fila e idempotência dependem de transações e locks corretos |
| Backend -> Meta Graph API | Chamada externa com token de página sensível; respostas não confiáveis |
| Pipeline -> persistência/logs/UI payloads | Erros/diagnósticos devem ser seguros (pt-BR resumido) sem segredos |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-01 | Information Disclosure | `services/social/facebook.py`, `publish_pipeline.py`, logs/`last_error` | mitigate | Descriptografar token apenas em memória no backend; nunca logar/retornar tokens, `access_token`, app secret ou payload bruto Graph. Persistir apenas mensagens pt-BR seguras e resumos sanitizados em `last_error`/`social_post_logs`. |
| T-17-02 | Tampering / Integrity (duplicidade) | `crud/social_posts.py` claim, `publish_pipeline.py` | mitigate | Claim atômico com `SELECT ... FOR UPDATE SKIP LOCKED` + transição para `publishing` antes do envio; no-op se `published`/`external_post_id`; não reenviar automaticamente em resultado ambíguo (D-09..D-11). |
| T-17-03 | Spoofing / Tampering (destino externo) | `facebook.py` URL de publicação | mitigate | Construir URL somente a partir de `settings.META_GRAPH_VERSION` e `page_id` confiável da conta persistida (`https://graph.facebook.com/{version}/{page_id}/feed`); nunca aceitar destino fornecido por usuário. |
| T-17-04 | Denial of Service | worker/pipeline retries | mitigate | Processar apenas elegíveis devidos, aplicar timeout explícito no `httpx.AsyncClient`, limitar tentativas por `SOCIAL_MAX_ATTEMPTS` e não agendar auto-retry para permanentes/reconexão necessária/esgotados. |
| T-17-05 | Elevation of Privilege | execução de worker/retry (módulos internos) | accept | Módulos desta wave não expõem rotas HTTP; proteção de endpoints cron/admin será aplicada na wave 17-02 (`require_cron_secret`/`require_admin`). |
</threat_model>
