| Token | Value | Usage |

| xs | 4px | Icon gaps, tight inline spacing |
| sm | 8px | Compact element spacing, small gaps |

60/30/10 intent: canvas dominates viewport; surface used for login card and existing container patterns; accent appears only on interactive/focus/brand elements.

## Interaction Contracts

### Login Page (`/admin/login`)

**Primary focal point:** password field + `Entrar` CTA within the centered login card.

| State | Trigger | UI | Behavior |
|-------|---------|----|----------|
| Default (logged out) | No `nqu_admin_token` in sessionStorage | Title, subtext, password field, Turnstile widget, `Entrar` disabled until password + cfToken present | No admin nav; show minimal branding and `Voltar ao site` link |
| Submitting | User clicks `Entrar` with valid local inputs | `Entrar` becomes loading `Entrando...`; inputs disabled as appropriate | Call `loginAdmin(password, cfToken)`; do not change auth contract |
| Success | `loginAdmin` resolves token | No persistent success message required | Store token in `sessionStorage[TOKEN_KEY]`; `router.replace(sanitizedNext ?? "/admin")` (D-02) |
| Invalid/error | `loginAdmin` rejects | Danger alert below form controls | Show safe error; reset Turnstile token/widget; keep user on login page |
| Already authenticated | Token present on `/admin/login` | Brief loading/blank guard acceptable | Redirect to sanitized `next` or `/admin` (D-04) |
| Missing Turnstile config | `NEXT_PUBLIC_TURNSTILE_SITE_KEY` absent in prod | Danger config message; login unavailable | Do not allow submit without valid Turnstile flow |

### Return-To / Guard

| Case | Input | Expected |
|------|-------|----------|
| Protected route, no session | `/admin/review` | Redirect to `/admin/login?next=%2Fadmin%2Freview` |
| Login success, valid next | `next=/admin/review` | Redirect to `/admin/review` |
| Login success, missing next | no `next` | Redirect to `/admin` |
| Login success, invalid next | `next=https://evil.example`, `//evil`, `/admin/login`, `\evil` | Fallback to `/admin` |
| Logout | user clicks Sair in admin chrome | Clear token, hard replace `/admin/login` |
| 401 from admin API | expired/invalid token | Clear token, redirect to `/admin/login` (preserve sanitized current path when available) |

## Responsive / Accessibility Contract

- Mobile-first; login card/container max width constrained (recommended `max-w-[420px]` or similar) and centered with comfortable padding (`px-4 py-8` or equivalent).
- Inputs and buttons keep minimum touch target height 44px (`min-h-11`).
- Visible focus uses existing `:focus-visible` accent-soft outline from admin.css; do not remove focus outlines.
- Error messages use `role="alert"` or `aria-live` where appropriate; loading state updates button text.
- Turnstile container must handle overflow on narrow screens (`overflow-hidden max-w-full` pattern already used).
- Respect `prefers-reduced-motion` (already in admin.css/public.css).
- Color contrast: keep existing token pairings (fg on canvas/surface, white on accent-strong, danger-soft on danger bg) and avoid introducing low-contrast muted text below current muted token.
