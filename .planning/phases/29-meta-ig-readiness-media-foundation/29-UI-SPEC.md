## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon/text gaps, tight inline spacing |
| sm | 8px | Button gaps, compact field spacing, badge padding blocks |
| md | 16px | Default padding inside cards/alerts, form/control gaps |
| lg | 24px | Card section padding, block separation within a panel |
| xl | 32px | Major section separation |
| 2xl | 48px | Page-level vertical rhythm where needed |
| 3xl | 64px | Rare page-level spacing only |

Exceptions: `44px` minimum touch target height for interactive controls (buttons, radios, inputs, icon buttons) per existing admin pattern and mobile accessibility. `2px` focus outline and `1px` borders are border/focus exceptions, not spacing tokens.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0f0a1a` (`--color-canvas`) | Page background, app canvas |
| Secondary (30%) | `#1a1025` (`--color-surface`) | Cards, dialogs, panels, secondary surfaces |
| Accent (10%) | `#8b5cf6` primary / `#a78bfa` soft text-focus / `#7c3aed` strong CTA / `#6d28d9` CTA hover | Accent-reserved elements only (see list) |
| Destructive | `#f87171` (`--color-danger`) | Destructive actions, destructive confirmation, blocking/error states |

**Supporting neutrals/borders (existing tokens, not accent):** `#2a1f3d` line, `#6d5a91` line-strong, `#e2e8f0` fg, `#b8a9cc` fg-muted, `#fecaca` danger-soft.

Accent reserved for:
- Primary action buttons (Connect/Reconnect/Verify/Confirm)
- Focus-visible outlines (`accent-soft`)
- Active/selected border or state indicator (selected page radio card, active integration status highlight)
- Key status emphasis badges/icons for ready/connected states
- Links or inline action emphasis where already used in admin pattern

Accent is **not** for body text blocks, destructive actions, validation error text, or large background fills except subtle low-opacity status/banner backgrounds already used by existing pattern.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | `Verificar agora` (when Facebook connected; verifies connection and refreshes IG readiness) |
| Secondary CTA (connect) | `Conectar Facebook` |
| Secondary CTA (reconnect) | `Reconectar` |
| Secondary CTA (disconnect) | `Desconectar` |
| Empty state heading | `Nenhuma Página do Facebook conectada` |
| Empty state body | `Conecte uma Página para habilitar a integração. Após conectar, você verá aqui a prontidão do Instagram para publicação.` |
| Error state | `Não foi possível confirmar a prontidão do Instagram agora. Tente novamente em alguns instantes. Se o problema continuar, reconecte sua Página do Facebook.` |
| Destructive confirmation | `Desconectar página`: `Tem certeza de que deseja desconectar esta Página do Facebook? A publicação automática do Facebook e a prontidão do Instagram ficarão indisponíveis até você conectar novamente.` |

### Instagram Readiness State Copy (META-01 / D-15)

| IG State | Heading / Badge | Message | Primary Action |
|----------|------------------|---------|----------------|
| `ready` | `Instagram pronto para publicação` | `Conta Instagram vinculada: @{ig_username}` when username available; otherwise `Conta Instagram vinculada (ID: {ig_user_id}).` | `Verificar agora` |
| `missing_linkage` | `Instagram não vinculado` | `Nenhuma conta Instagram Business/Creator vinculada a esta Página.` | `Reconectar` |
| `missing_permissions` | `Permissões do Instagram ausentes` | `Permissões do Instagram ausentes. Reconecte para autorizar o Instagram.` | `Reconectar` |
| `needs_reconnect` | `Reconexão necessária para o Instagram` | `A conexão do Instagram precisa ser renovada. Reconecte para continuar.` | `Reconectar` |
| `unknown` / check failed | `Prontidão do Instagram indisponível` | `Não foi possível confirmar a prontidão do Instagram agora.` | `Verificar agora` or `Reconectar` depending on backend actionability |

**Readiness copy rules:**
- Messages must be safe pt-BR, actionable, and never expose tokens, raw Graph errors, or internal IDs except safe IG user/page identifiers already intended for admin display.
- IG readiness is additive: Facebook-connected state remains visible when IG is not ready (D-15). Do not present FB as disconnected solely because IG lacks linkage/scopes.

### Media Validation Feedback Contract (IMAG-01 / D-04, consumed by Phase 30/31)

| State | Feedback | Blocking Scope |
|-------|----------|----------------|
| Missing image | `Imagem ausente para Instagram. Gere o card da vaga antes de publicar no Instagram.` | Blocks Instagram only; Facebook/site unaffected |
| Invalid image | `Imagem inválida para Instagram. Verifique o formato, tamanho ou disponibilidade pública antes de publicar.` | Blocks Instagram only; Facebook/site unaffected |
| Public URL invalid | `A imagem do Instagram não está acessível por uma URL pública HTTPS. Revise a configuração de mídia antes de publicar.` | Blocks Instagram only; Facebook/site unaffected |
| Ready image | `Imagem pronta para publicação no Instagram.` | No block |

**Validation contract note:** Phase 29 delivers backend validation contracts and copy primitives. Phase 30 owns review-dialog enforcement UX; Phase 31 revalidates before publish. UI-SPEC does not claim full review blocking UI is implemented in Phase 29.

## Interaction Contract

| Interaction | Trigger | Expected Result | Accessibility |
|-------------|---------|-----------------|---------------|
| Load Integrations | Page mount with admin token | Fetch Meta status; render FB status and additive IG readiness; no Graph call implied beyond existing verify/connect flows | Loading text visible; preserve focus order |
| Verify now | Click `Verificar agora` | Runs existing verify flow; refreshes FB + IG readiness state; on transient failure keep current connected FB state and show safe error | Button disabled/loading state; message announced via visible banner/text |
| Reconnect Instagram/Facebook | Click `Reconectar` | Starts OAuth flow; user returns to callback states; on missing IG permissions/linkage after connect, show actionable IG state, not FB-broken state | Same keyboard/focus behavior as existing connect button |
| Disconnect | Click `Desconectar` then confirm | Disconnects integration; both FB publish and IG readiness become unavailable until reconnect | `dialog` with cancel default focus path; Esc closes unless action loading |
| IG image invalid (contract) | Phase 30/31 attempts IG publish/preview with invalid image | Show clear pt-BR validation; block only IG action; allow FB/site flows per D-04 | Error text associated with IG section/action; no color-only signaling |
