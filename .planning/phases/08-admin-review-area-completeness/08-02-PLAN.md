# Phase 8 — Wave 2: Approve and Edit Actions

## Objective

Implement the approve and edit actions for admin job review, so that an admin can approve a job (changing status to `published` and refreshing `expires_at`) or edit a job (partial update with contact validation). This delivers the core review workflow functionality.

## Purpose

Wave 2 implements the heart of the admin review criteria: criteria 2 (approve + edit with contact validation). Without these actions, the admin queue is read-only. This wave also integrates the Toast notification feedback that is required by criteria 5.

    ```python
    async def approve_job(db: AsyncSession, job_id: str) -> Job:
        """Aprova uma vaga: status → published, refresca expires_at para now + 14 dias."""
        job = await db.get(Job, job_id)
        if not job:
            raise HTTPException(status_code=404, detail="Vaga não encontrada")
        job.status = JobStatus.published
        job.expires_at = datetime.utcnow() + timedelta(days=14)
        job.updated_at = datetime.utcnow()
        db.add(job)
        await db.commit()
        await db.refresh(job)
        return job

    async def update_job(db: AsyncSession, job_id: str, job_in: JobUpdate) -> Job:
        """Partial update de uma vaga. Apenas campos fornecidos são aplicados.
        Se ambos contact_email e contact_phone forem nulos/blank, DB CHECK lança IntegrityError."""
        job = await db.get(Job, job_id)
        if not job:
            raise HTTPException(status_code=404, detail="Vaga não encontrada")
        # Build update dict only from provided fields (Pydantic partial semantics)
        update_data = job_in.model_dump(exclude_unset=True)
        for field, value in update_data.items():
            setattr(job, field, value)
        try:
            db.add(job)
            await db.commit()
            await db.refresh(job)
            return job
        except IntegrityError as e:
            # DB CHECK at_least_one_contact violated
            raise HTTPException(
                status_code=422,
                detail="Vaga precisa ter ao menos um contato (email ou telefone)"
            ) from e
    ```
