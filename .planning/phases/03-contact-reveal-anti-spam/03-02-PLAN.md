API do slowapi 0.1.10 (verificada no wheel em 2026-10-21):
- `from slowapi import Limiter` — `Limiter(key_func, default_limits=[], headers_enabled=False, storage_uri=None, enabled=True)`. `key_func` é obrigatório e recebe o `Request`.
- `from slowapi.errors import RateLimitExceeded` — subclasse de `starlette.exceptions.HTTPException`, status 429, atributo `.limit` (wrapper `Limit` do slowapi, que por sua vez tem `.limit` = `limits.RateLimitItem`, com `.get_expiry()`).
- O decorator `@limiter.limit(limit_value)` aceita **string ou callable** (`StrOrCallableStr`): um callable de 0 argumentos é resolvido **a cada request** (o `LimitGroup` re-resolve no `_check_request_limit`), então o limite por env é dinâmico.
- O decorator **levanta** `RateLimitExceeded` quando o bucket estoura; o handler registrado no app transforma em resposta.
- O endpoint decorado **precisa** declarar `request: Request` no signature.
- `Limiter.reset()` limpa o storage in-memory (usado pela fixture autouse).
