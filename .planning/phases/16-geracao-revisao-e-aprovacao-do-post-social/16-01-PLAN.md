<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin/API -> backend services | Entradas de draft/schedule são controladas por admin autenticado mas devem ser validadas e normalizadas server-side |
| Backend -> LLM (Groq) | Conteúdo da vaga é dado não confiável no prompt; resposta do LLM pode vazar/incluir dados proibidos |
| Backend -> persistência/config | Segredos/config e texto aprovado/draft persistidos não podem vazar; link público não pode ser inventado |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-01 | Tampering (E prompt injection) | `services/social/post_generation.py` prompt/LLM call | mitigate | Tratar campos do Job como dados (prompt claro), nunca confiar na saída: pós-processar com política central que remove empresa/contato e normaliza link/limites (D-15/D-17). |
| T-16-02 | Information Disclosure | geração/template/fallback/schemas | mitigate | Aplicar política central: excluir `company`, `contact_email`, `contact_phone` e padrões óbvios de e-mail/telefone do texto; flag `SOCIAL_POST_INCLUDE_CONTACT` default `False`; não logar segredos nem texto sensível desnecessário. |
| T-16-03 | Tampering/Integrity | link público e agendamento | mitigate | Construir link apenas como `{SITE_PUBLIC_URL.rstrip('/')}/?vaga={job_id}` após validar URL http/https; se ausente/inválida lançar erro acionável específico (sem inventar). Converter `America/Sao_Paulo` -> `datetime` timezone-aware via `zoneinfo` para `scheduled_at`. |
| T-16-04 | Denial of Service (availability of review) | fallback de geração | mitigate | Capturar falhas/timeout/ausência de Groq e retornar draft determinístico de template com origem/fallback; nunca propagar falha que bloqueie fluxo de revisão (D-03/POST-02). |
| T-16-05 | Elevation of Privilege | módulos backend desta fundação | accept | Módulos não expõem rotas por si; autenticação/autorização admin será aplicada nos endpoints do plano 16-02. |
</threat_model>
