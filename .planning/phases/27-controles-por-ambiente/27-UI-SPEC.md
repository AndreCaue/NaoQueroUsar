## Component Behavior Contract (Phase-Specific)

### 1) Ad Slots — ADS-01 (D-01, D-02, D-03)

| State | Condition | Render | Layout |
|-------|-----------|--------|--------|
| Ads visible (default) | `NEXT_PUBLIC_ADS_ENABLED` absent, empty, or any value not explicitly disabled | Render current `AdSlot` markup unchanged | Current spacing/layout preserved |
| Ads hidden | `NEXT_PUBLIC_ADS_ENABLED` explicitly disabled (`false`, `0`, `off`, `no`, `disabled`, case-insensitive, trimmed) | Render nothing (`null`) for all variants | Collapse space; no empty dashed placeholder, no residual aria-label |

**Placements covered (all uniform, D-03):**

| Placement | File | Variant | Expected when hidden |
|-----------|------|---------|----------------------|
| Header ad | `frontend/app/(public)/page.tsx` | `header` | Absent from DOM |
| Sidebar ad | `frontend/app/(public)/page.tsx` | `sidebar` | Absent from DOM |
| Inline grid ad | `frontend/components/board/JobGrid.tsx` | `inline` | Absent from DOM; grid items reflow naturally |

**Gate:** Centralize in `frontend/components/board/AdSlot.tsx` (or equivalent single gate). Do not scatter placement conditionals.

**A11y:** When visible, keep `role="complementary"` and `aria-label="Espaço publicitário"`. When hidden, emit no ad landmark.

### 2) Doações Button — DONA-01 (D-04, D-05, D-06)

| State | Condition | Element | Destination | Attributes |
|-------|-----------|---------|-------------|------------|
| External configured | `NEXT_PUBLIC_DONATION_URL` is a valid absolute `http:` or `https:` URL | `<a>` | Configured URL | `target="_blank" rel="noopener noreferrer"`; same visible classes/text |
| Safe fallback | Env absent, empty, invalid, `javascript:`, `data:`, relative, or malformed | `<Link>` | `/doacoes` | No `target="_blank"`; same visible classes/text |

**Visual parity rule:** Both states must use identical classes, label, size, and hover/focus treatment:

```text
inline-flex min-h-11 min-w-11 items-center justify-center rounded-md border border-[rgba(250,204,21,0.40)] px-3 text-sm font-semibold text-donate hover:border-donate hover:bg-[rgba(250,204,21,0.12)]
```

**D-06:** `/doacoes` page remains accessible at all times, regardless of env configuration. No redirect required.

**Security:** Do not render unvalidated env URL. Only absolute `http:`/`https:` pass. All other values fall back to `/doacoes`.

## Responsive / Layout Impact

| Breakpoint | Ads enabled | Ads disabled |
|------------|-------------|--------------|
| Mobile (`<lg`) | Header ad visible; inline ads in grid; sidebar hidden by existing class | Header and inline absent; no empty gaps; grid flows normally |
| Desktop (`>=lg`) | Header ad, sidebar ad (`lg:flex sticky top-24`), inline ads | All absent; content column remains `min-w-0`; sidebar column collapses only if implementation removes aside content — preferred: `AdSlot` returns null so aside becomes empty; executor should verify no awkward empty 300px gutter. If empty gutter appears, collapse aside rendering conditionally. |

**Recommendation (discretion):** Collapse by returning `null` from `AdSlot`. Verify desktop layout; if `aside` preserves a 300px empty track, conditionally omit the aside when ads disabled.
