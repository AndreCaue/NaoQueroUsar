<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin browser → authenticated integrations API | Bearer-authenticated requests for start/status/verify/select/disconnect; inputs must be authorized and validated |
| Meta redirect/browser → callback endpoint | Unauthenticated HTTP callback carries attacker-controlled query params (`code`, `state`, `error`); trust established only by signed state validation |
| Backend API/service → Meta Graph API | External token exchange and debug endpoints can fail, return sensitive data, or behave unexpectedly |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-07 | Spoofing | `GET /meta/oauth/callback` (`integrations.py`, `meta_oauth.py`) | mitigate | Treat callback as untrusted; require valid signed stateless state (purpose/nonce/exp/HS256) before any exchange/persistence and reject otherwise with safe redirect (D-01, D-03, D-04). |
| T-15-08 | Elevation of Privilege | `start/status/verify/select/disconnect/pending-selection` routes | mitigate | Enforce `Depends(require_admin)` on all sensitive operations; ensure selection confirmation only consumes pending records created by backend flow and scoped to valid nonce/context (D-04, D-05, D-08). |
| T-15-09 | Information Disclosure | Redirects, JSON responses, exceptions/logs | mitigate | Return only safe result codes and sanitized payloads; never include access tokens, app secret, encryption key, OAuth code, or raw Graph errors in query params, responses, or logs (META-05, D-03, D-11). |
| T-15-10 | Tampering | Connection state persistence on callback/selection/disconnect | mitigate | Persist connected state only after successful validated exchange/selection, replace single active connection atomically, consume pending selection once, and clear usable credentials on disconnect (D-06, D-07, D-08). |
| T-15-11 | Denial of Service (operational) | Verify/status and callback validation paths under external failures | mitigate | Use explicit HTTP timeouts, classify transient Graph/network/5xx/429 failures without downgrading valid connections, and surface safe retryable verification errors (D-10). |
| T-15-12 | Spoofing | Misconfigured OAuth redirect/config handling | mitigate | Build dialog/exchange URLs from server-side `META_*` settings only; fail closed with safe "não configurada" errors when required config is missing, preventing unsafe fallback targets (META-02, D-02). |
</threat_model>
