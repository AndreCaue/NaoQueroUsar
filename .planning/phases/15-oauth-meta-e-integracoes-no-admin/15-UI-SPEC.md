# Phase 15 — UI Design Contract

> Visual and interaction contract for the admin Integrações (Meta/Facebook OAuth) screen. Generated by gsd-ui-researcher from existing admin tokens/components and Phase 15 CONTEXT/RESEARCH/REQUIREMENTS. Verified by gsd-ui-checker.

**Scope:** New dedicated admin page/section `Integrações` for connecting, selecting, verifying, reconnecting, and disconnecting a single Facebook Page (META-01..META-06, D-13..D-16). No publication/status-per-job UI (Phase 17) and no post draft/review UI (Phase 16).

**Primary focal point:** the connection Status card and its state-appropriate primary CTA (e.g. `Conectar Facebook`, `Reconectar`, `Confirmar página`) — headers, banners, metadata, and secondary actions support this decision and action.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, tight inline spacing, badge internal padding adjustments |
| sm | 8px | Gaps between related controls (button groups), compact form spacing |
| md | 16px | Default element spacing, card content gaps, input/button internal rhythm |
| lg | 24px | Card padding (`p-6`), section/content separation within page |
| xl | 32px | Page vertical rhythm between header, banners, and main card/sections (`py-8`, `mb-8`) |
| 2xl | 48px | Major section breaks (only if page grows beyond single primary card) |
| 3xl | 64px | Page-level spacing (reserved; avoid on dense admin utility screen) |

Exceptions: `44px` minimum touch target height for all interactive controls (`.touch-target` / `min-h-[44px]`) — accessibility exception per existing admin CSS. Border radii follow tokens: cards `12px` (`rounded-[12px]` / `--radius-card`), dialogs `16px` (`--radius-dialog`).

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px (`text-base`) | 400 (regular) | 1.5 (`leading-normal`) |
| Label | 14px (`text-sm`) | 400 (regular) for secondary/meta; 600 (semibold) for emphasis/CTAs | 1.5 (`leading-normal`) |
| Heading | 20px (`text-xl`) | 600 (semibold) | 1.2 (`leading-tight`) |
| Display | 30px (`text-3xl`) | 600 (semibold) | 1.2 (`leading-tight`, `tracking-tight`) |

**Rules:** Use exactly two weights (400, 600). Page title uses Display (`h1`, `text-3xl font-semibold leading-tight tracking-tight`). Section/card titles use Heading (`h2`, `text-xl font-semibold`). Status descriptions, helper/error text, timestamps/meta use Body or Label at 400 with `text-fg-muted` where secondary. Primary action labels use Label/Body size with 600 as needed for clarity. No additional font sizes without updating this contract.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0f0a1a` (`--color-canvas` / `bg-canvas`) | Page background, app shell |
| Secondary (30%) | `#1a1025` (`--color-surface` / `bg-surface`) | Integration status card/panels, dialogs, contextual banner surfaces (tinted variants allowed per state) |
| Accent (10%) | `#8b5cf6` (`--color-accent`) and `#a78bfa` (`--color-accent-soft`) | Reserved for: primary positive CTAs (`Conectar Facebook`, `Reconectar`, `Confirmar página`), active/hover/focus borders on interactive cards/controls, focus-visible outline (`#a78bfa`), navigation/inline action links, selected/pending selection emphasis, connected-status emphasis chip/badge accent treatment |
| Destructive | `#f87171` (`--color-danger`, soft `#fecaca`) | Destructive actions only: `Desconectar` button/confirm action styling and destructive confirmation dialog emphasis |

**Supporting tokens (existing, not additional accents):** `#2a1f3d` (`--color-line`) borders/dividers, `#6d5a91` (`--color-line-strong`) strong borders, `#e2e8f0` (`--color-fg`) primary text, `#b8a9cc` (`--color-fg-muted`) secondary text, `#7c3aed`/`#6d28d9` accent strong states for primary filled buttons if used.

**Accent reserved for:** primary connect/reconnect/confirm CTAs, focus rings and focus/hover border emphasis, active admin nav indication for Integrações (if applied), selected page row/card in pending selection, and non-destructive status/action highlights. **Never** use accent for destructive actions, generic body text blocks, or all interactive elements indiscriminately.

**State color semantics (safe, non-secret):**
- `connected`: success/healthy emphasis may use accent-tinted badge/surface; text must clearly state "Conectado".
- `needs_reconnect`: warning/alert banner and status badge (high-contrast against canvas/surface) with clear reconnect CTA; do not imply success.
- `disconnected`: neutral/muted presentation with primary connect CTA.
- `pending_selection`: accent-emphasized selection state and confirm CTA.
- Transient verification error (D-10): error/warning banner without changing a previously valid connection to disconnected styling.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | `Conectar Facebook` (estado `disconnected`, sem conexão ativa) |
| Secondary CTAs (by state) | `Verificar agora` (connected), `Reconectar` (needs_reconnect ou fluxo de reconexão), `Confirmar página` (pending selection, habilitado apenas com 1 página selecionada), `Desconectar` (connected/needs_reconnect, abre confirmação), `Voltar ao painel` (apoio opcional) |
| Page title | `Integrações` |
| Page subtitle | `Conecte sua Página do Facebook para publicar vagas automaticamente quando a integração estiver ativa.` |
| Empty/disconnected heading | `Nenhuma Página do Facebook conectada` |
| Empty/disconnected body | `Conecte uma Página para habilitar a publicação automática de vagas no Facebook. Você será redirecionado para o Meta em uma etapa segura no servidor.` |
| Pending selection heading | `Selecione a Página do Facebook` |
| Pending selection body | `Encontramos mais de uma Página disponível. Escolha apenas uma para concluir a conexão desta conta.` |
| Connected heading | `Página do Facebook conectada` |
| Connected body | `A integração está ativa para a página exibida abaixo. Você pode verificar a conexão agora ou desconectar quando quiser.` |
| Needs reconnect heading | `Reconexão necessária` |
| Needs reconnect body | `A conexão com o Facebook precisa ser renovada. Reconecte para continuar usando a integração com segurança.` |
| Error state (generic, safe) | `Não foi possível concluir a ação. Tente novamente em alguns instantes. Se o problema continuar, reconecte sua Página do Facebook.` |
| Transient verification error (preserve valid state) | `Não foi possível verificar a conexão agora. Sua conexão atual foi mantida. Tente novamente em alguns instantes.` |
| Callback banner — success | `Página do Facebook conectada com sucesso.` |
| Callback banner — cancelled | `Conexão com o Facebook cancelada. Nenhuma alteração foi feita.` |
| Callback banner — error | `Não foi possível conectar ao Facebook. Tente novamente.` |
| Callback banner — selection required | `Escolha uma Página do Facebook para concluir a conexão.` |
| Destructive confirmation | `Desconectar: Tem certeza de que deseja desconectar esta Página do Facebook? A publicação automática ficará indisponível até você conectar novamente.` |
| Destructive confirm actions | Confirmar: `Desconectar página` · Cancelar: `Manter conexão` |
| Loading states | `Carregando integrações...`, `Verificando conexão...`, `Conectando...`, `Desconectando...` (conforme ação) |
| Page metadata labels | `Página`: `{page_name}` · `ID da página`: `{page_id}` (quando disponível) · `Conectado em`: `{data}` · `Última verificação`: `{data}` (somente dados seguros do payload, sem tokens) |

**Copy rules:** pt-BR, claro e seguro. Never mention tokens, secrets, internal IDs de OAuth, stack traces, ou detalhes sensíveis retornados pelo Meta/backend. Error/alert summaries shown in UI must come from sanitized backend codes/messages only (D-03, D-11, META-05).

## Component Inventory (Phase 15)

| Component / Area | Purpose | States / Behavior |
|------------------|---------|-------------------|
| Admin nav entry "Integrações" | Discoverability from admin shell | Link in `admin/layout.tsx` nav consistent with existing admin links; visible to authenticated admin flow |
| Integrations page header | Context/title | Display + subtitle; always visible |
| Contextual callback banner | Communicate redirect outcome (D-16) | `success`, `error`, `cancelled`, `select_page`; dismissible or persistent-on-load per existing toast/banner pattern; no secrets in query-derived text |
| Status card (primary) | Show connection state and details (D-11, D-14) | `disconnected`, `pending_selection`, `connected`, `needs_reconnect`, `loading`; renders safe fields only (status, page name/id, connected_at, token_checked_at, alert summary) |
| Page selection list | Explicit page choice when multiple pages (D-05, D-08) | Radio/selectable rows/cards with page name + page id; no tokens; requires selection before `Confirmar página`; empty/expired pending handled as safe error prompting reconnect |
| Action toolbar/buttons | State-appropriate CTAs (D-12, D-14) | Renders only relevant actions per state; buttons meet 44px touch target; loading/disabled during in-flight requests |
| Disconnect confirmation dialog | Prevent accidental destructive action (D-15) | Native `<dialog>` or existing admin dialog pattern; explicit confirm/cancel; destructive styling on confirm action only |
| Inline/toast feedback | Action result feedback | Reuse `ToastProvider` patterns for success/error of verify/disconnect/confirm actions where appropriate |

**Interaction contracts:** "Conectar" and "Reconectar" initiate same-tab backend-mediated OAuth flow (D-02, D-04). "Verificar agora" performs on-demand validation and updates status without degrading valid connection on transient failure (D-09, D-10). "Desconectar" requires confirmation before API call (D-15, D-07). Pending selection confirmation is authenticated and persists only the selected single page (D-05, D-06, D-08).
