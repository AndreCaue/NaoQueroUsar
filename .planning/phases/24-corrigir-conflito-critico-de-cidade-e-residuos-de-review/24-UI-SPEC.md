## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, tight inline spacing |
| sm | 8px | Compact element spacing, small gaps |
| md | 16px | Default padding/spacing in cards, sections, dialog body |
| lg | 24px | Section separation, larger layout padding |
| xl | 32px | Major layout gaps |
| 2xl | 48px | Major section breaks (reserved) |
| 3xl | 64px | Page-level spacing (reserved) |

Exceptions: `12px` (`p-3`, `gap-3`, `py-3`) is already used throughout chat components and dialog sections; preserve existing 12px usage in touched files. `44px` minimum touch target is required for interactive controls (`min-h-11`, `h-11 w-11`) — accessibility exception, not a spacing-scale token.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0f0a1a` (`--color-canvas`) | Page background, canvas surfaces |
| Secondary (30%) | `#1a1025` (`--color-surface`) | Cards, chat panel, dialog surface, elevated controls |
| Accent (10%) | `#8b5cf6` (`--color-accent`) / `#a78bfa` (`--color-accent-soft`) / `#7c3aed` (`--color-accent-strong`) | Accent reserved below |
| Destructive | `#f87171` (`--color-danger`) | Destructive/error states only; no destructive action added in Phase 24 |

**Supporting tokens (pre-existing, preserve):** `--color-line: #2a1f3d`, `--color-line-strong: #6d5a91`, `--color-fg: #e2e8f0`, `--color-fg-muted: #b8a9cc`, `--color-accent-strong-hover: #6d28d9`, `--color-danger-soft: #fecaca`, `--color-donate: #facc15`.

Accent reserved for: focus rings (`--color-accent-soft`), primary filled CTA background/text pairing (`--color-accent-strong` + white), interactive border/hover emphasis on chat actions and card focus-within, active chat launcher emphasis, and existing brand indicators. Accent is **not** used for all interactive elements; secondary controls use `line-strong`/`fg-muted` with accent only on hover/focus per existing pattern.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Preserve existing CTAs; no new primary CTA in Phase 24. Existing chat submit: "Buscar vagas" / existing reveal CTA remains unchanged. |
| Empty state heading | Preserve existing: "Descreva a vaga que você procura" (chat empty) / "Nenhuma vaga encontrada" (results empty) as currently implemented. |
| Empty state body | Preserve existing guidance text; do not alter empty-state copy in this phase. |
| Error state | Preserve existing safe pt-BR messages (e.g., "Não foi possível buscar agora."). WR-01 fix must not introduce opaque/internal errors. |
| Destructive confirmation | No destructive actions in Phase 24 scope. |

**Phase 24 interaction/copy constraints:**
- WR-01: closing job detail opened from chat must restore keyboard focus to a mounted, stable control (preferred: the originating chat result trigger if still mounted; fallback: chat close button / launcher only when mounted and visible). Focus must never land on `document.body` in keyboard flow.
- No user-visible copy change is required for WR-01/WR-03/CR-01. Any temporary status text, if added for a11y, must be pt-BR, specific, and non-technical.
- Chat remains no-login, mobile-first, and must not expose contact data in payload/UI.
