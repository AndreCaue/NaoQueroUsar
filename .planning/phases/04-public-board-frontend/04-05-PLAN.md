  <action>
Create `BoardToolbar.tsx` (`"use client"`): props `{ filters: Filters; total: number }`.

Navigation helper:
```ts
const router = useRouter();
const [isPending, startTransition] = useTransition();
const commit = (patch: Partial&lt;Filters&gt;) =&gt; {
  const next = { ...filters, page: 1, vaga: null, ...patch };
  startTransition(() =&gt; router.replace(buildBoardHref(next), { scroll: false }));
};
```
Always drop `vaga` and reset `page` when a filter changes. Never use `router.push` for filters.

Search:
- Local state `value` initialised from `filters.q`; a `lastCommitted` ref keeps the input from being clobbered mid-typing when the server value arrives.
- `useEffect` (300 ms) commits `{ q: value.trim() }` when `value.trim() !== filters.q`; cleanup clears the timer.
- `Enter` (`onKeyDown`) clears the timer and commits immediately; `Escape` clears the field and commits `{ q: "" }`.
- Input: `type="text"`, `inputMode="search"`, `enterKeyHint="search"`, `autoComplete="off"`, `maxLength={80}`, `aria-label="Buscar vagas"`, placeholder `Busque por cargo, empresa ou palavra-chave`, `h-12` (48px), `bg-canvas`, `border border-line-strong`, `rounded-lg`, focus ring `focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-accent-soft`. Search icon 20px on the left (`aria-hidden`).
- Clear button only when `value !== ""`: 44×44, `aria-label="Limpar busca"`, ghost style; clears state and commits immediately (no debounce).

City chips:
- `div role="group" aria-label="Filtrar por cidade"`; first chip `Todas` (`city: null`), then `CITY_OPTIONS` in the fixed order São Paulo, Rio de Janeiro, Belo Horizonte, Remoto.
- Single-select; `aria-pressed={active}`; selected = `bg-accent-strong text-white font-semibold`; unselected = `border border-line-strong text-fg hover:border-accent hover:text-accent-soft`; all `min-h-11 px-4 rounded-full text-sm`.
- Mobile: `-mx-4 flex gap-2 overflow-x-auto px-4 pb-1 [scrollbar-width:none] sm:mx-0 sm:flex-wrap sm:overflow-visible`.

Sort:
- Native `select` with `aria-label="Ordenar por"`, `h-11 w-40`, `bg-canvas`, `border border-line-strong`; options `Mais recentes` (`recentes`) and `Mais antigas` (`antigas`); `onChange` commits `{ sort }`.

Count:
- `p aria-live="polite" role="status"` with `formatJobCount(total)` (import from `lib/format`); render only when `total &gt; 0` (the empty state replaces the count).

Layout:
- Sticky wrapper `sticky top-16 z-10 -mx-4 border-b border-line bg-canvas px-4 py-3 sm:mx-0 sm:px-0` with `aria-busy={isPending}`.
- DOM order: search form (`role="search"`) → chips → row with count (left) and sort (right); on mobile the count/sort row stays one line.
- No `backdrop-filter`, no animation beyond colour/opacity transitions, and respect `prefers-reduced-motion` via the global rule from 04-01.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user input → URL | `q` is free text written into the query string |
| URL → RSC | Params are re-parsed on every navigation |
| client → server | Every keystroke can trigger a request (debounced) |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-04-18 | Denial of Service | debounce/request volume | mitigate | 300 ms debounce, immediate commit only on Enter/clear/chip change, `startTransition` so rapid changes coalesce; backend keeps the limiter |
| T-04-19 | Tampering | URL/state desync | mitigate | One parser (`normalizeFilters`); unknown city/sort ignored; filter changes always reset `page` and drop `vaga`; no `localStorage` |
