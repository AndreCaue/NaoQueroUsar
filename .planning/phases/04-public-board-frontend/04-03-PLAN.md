`lib/jobs.ts` (server-only helpers; no `"use client"`):
- `const API = process.env.BACKEND_API_URL ?? process.env.NEXT_PUBLIC_API_URL ?? "http://localhost:8000";` — server-side var first so a deployed build does not pin the build machine's public URL.
- `export class BoardError extends Error { kind: "timeout" | "http" | "network"; status?: number }`.
- `fetchBoard(filters: Filters)`: `new URLSearchParams(toApiParams(filters))`, add `limit=PAGE_SIZE`, fetch `${API}/api/v1/public/jobs?...` with `cache: "no-store"`, `signal: AbortSignal.timeout(15_000)`. `!res.ok` → throw `BoardError("http")` with status; timeout/abort (`DOMException` name `TimeoutError`/`AbortError`) → `BoardError("timeout")`; anything else → `BoardError("network")`. Return the parsed `JobListResponse`.
- `fetchJob(id: string)`: GET `${API}/api/v1/public/jobs/${id}` with the same cache/timeout; `404` → `null`; other non-OK → throw `BoardError("http")`; return `JobPublic`.

`lib/filters.ts`:
- `export const PAGE_SIZE = 24;`
- `export type Sort = "recentes" | "antigas";`
- `export interface Filters { q: string; city: string | null; sort: Sort; page: number; vaga: string | null }`
- `normalizeFilters(input: Record of string-or-string-array): Filters` — take the first value of arrays; trim `q` and cap at 80 chars; `city` only when it is one of the 4 slugs; `sort` only `antigas`, else `recentes`; `page` integer ≥ 1 (NaN → 1); `vaga` only when `isUuid()`.
- `isUuid(value: string): boolean` — generic UUID regex, case-insensitive, any version.
- `toApiParams(f: Filters): Record of strings` — `q` (if non-empty), `city` (the slug — the backend accepts it), `sort`, `page`, plus `vaga` is deliberately NOT sent to the API.
- `buildBoardHref(f: Filters): string` — `/` + `URLSearchParams`, omitting empty `q`, null `city`, `sort === "recentes"`, `page === 1` and null `vaga`.
- `hasActiveFilters(f)` → `Boolean(f.q || f.city)`.

`lib/format.ts`: `formatDateBR(iso)` using one module-level `Intl.DateTimeFormat("pt-BR", { day: "2-digit", month: "2-digit", year: "numeric", timeZone: "America/Sao_Paulo" })`; `formatJobCount(n)` returning `1 vaga encontrada` / `${n} vagas encontradas`.

`lib/cities.ts`: `CITY_OPTIONS` (slug/label/canonical from the table), `cityLabel(canonical: string): string` (canonical → accented label; unknown → the value unchanged), `cityBySlug(slug: string | null)`.
